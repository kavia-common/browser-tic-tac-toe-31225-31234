# browser-tic-tac-toe-31225-31234

This workspace includes ESLint and Prettier tooling inside the frontend app. See `tic_tac_toe_frontend/README.md` for usage.

This workspace contains a minimal React + Vite Tic Tac Toe app styled with the Ocean Professional theme.

## Structure
- tic_tac_toe_frontend — React application (TypeScript, Vite)

## Quick Start
1. cd tic_tac_toe_frontend
2. npm install
3. npm run dev
4. Open the URL printed in the console (e.g., http://localhost:5173)
